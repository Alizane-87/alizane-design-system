## 🚀 Quickstart (Local Development)

```bash
# 1. Navigate to the standalone repo
cd alizane-design-system

# 2. Install dependencies
npm install

# 3. Start development server on port 3001
npm run dev
```

Open [http://localhost:3001](http://localhost:3001) to explore the full interactive studio.

---

## 🛠️ Tech Stack
- **Framework:** Next.js 16 (App Router, React 19)
- **Styling:** Tailwind CSS v4
- **Typography:** Fontshare CDN + Google Fonts + Variable Web Fonts
- **Animations:** Hardware-accelerated CSS transforms, requestAnimationFrame Canvas loops, IntersectionObserver

---

## 🚢 Deploying to Vercel

1. Push this directory to a new GitHub repo: `github.com/your-org/alizane-design-system`.
2. Import project in Vercel.
3. Assign custom domain: `studio.alizanelabs.site`
4. Instant live agency showcase!
